# キャラの画像（アイコン）

ここに `<id>.png`（`.webp`・`.jpg` も可）を置くと、画面のキャラのアイコンがその画像になります。無いキャラは、下の「丸の色」の丸に名前の頭の文字を入れて表示します。

- 置いたら `npm run build` でビルドし直す（一覧はビルドのときに読む: `vite.config.ts` の `charaImages`。開発用のサーバーは開き直す）
- 形: 正方形。推奨 **256×256 px**（画面では 22〜46 px の丸に切り抜いて出す。高解像度の画面でも粗くならない大きさ）。顔を中央に、丸く切り抜かれても欠けないよう周りに余白を少し
- 背景: 透明でも可（透明の所はアイコンの面の色になる）。丸の縁はカードの枠の色（レベル）で、画像の外側に付く
- 容量: 1 枚 60 KB 以下が目安（36 枚で約 2 MB）
- 差し替え: 同じ名前で上書きする。消すと丸の表示に戻る
- 生成した画像を置いたときは、その記録をこのファイルの末尾に書く（ツール・日付・プロンプトの要点）
